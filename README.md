# Monaco Editor Format Options Test

A React + TypeScript + Vite app that wraps `@monaco-editor/react` with:

- a reusable MonacoEditor component
- a reusable `MonacoEditorToolbar`
- Lucide icons
- format on mount
- format on blur
- format on paste
- format on save via Ctrl/Cmd + S
- readonly handling
- imperative handle methods:
  - `formatDocument()`
  - `copyText()`
  - `getEditor()`
  - `getMonaco()`
  - `getStatus()`
  - `setStatus()`

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
